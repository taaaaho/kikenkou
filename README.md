# kikenkou

iOSアプリ「危険物 甲種・乙種 合格予測（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/kikenkou/
- プライバシーポリシー: https://taaaaho.github.io/kikenkou/privacy.html
- 利用規約: https://taaaaho.github.io/kikenkou/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、一般財団法人消防試験研究センターその他の団体とは提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`kikenkou-code`）で管理しています。
